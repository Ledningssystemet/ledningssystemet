# Ledningssystemet

Ledningssystemet is an open-source management system for documenting, organizing, and improving business processes and quality management work. It supports work toward standards and regulations such as ISO 9001, ISO 14001, ISO 45001, ISO/IEC 27001, GDPR and NIS2; using the software does not itself establish compliance.

Features include process and document management, roles and permissions, activity logging, import/export, risks, incidents, and GDPR records of processing activities. [Training videos](https://support.ledningssystemet.se/kb/faq.php?cid=3) show examples of the interface.
